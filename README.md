# Capybara Code

**Capybara Code** is an experimental open-source AI coding agent optimized for GPT models.

The project aims to build a fast, transparent, and extensible coding harness inspired by tools such as Codex and OpenCode.

> Capybara Code is currently under active development and is not recommended as a primary coding agent yet.

## Features

- Interactive CLI and TUI
- File search, reading, and editing
- Real-time task and tool execution logs
- TODO and task planning
- Sub-agent execution
- MCP and Skills support
- LSP integration
- Token, context, cost, and runtime tracking
- Extensible model provider architecture

## Installation

```bash
none
````

## Project Goal

Capybara Code is built to explore how much performance can be gained through a better AI coding harness—not only through stronger models.

The long-term goal is to create a state-of-the-art coding agent with strong planning, tool use, context management, verification, and multi-agent workflows.
